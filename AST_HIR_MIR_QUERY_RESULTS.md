# AST/HIR/MIR Type Query Results

## Query Tool: `query_ast_types`

Successfully queried `string_usage.parquet` for AST/HIR/MIR type references in rustc_driver.so.

## Summary Statistics

**Total patterns found**: 8 out of 20 searched

| Pattern | Matches | Description |
|---------|---------|-------------|
| **Def** | 849 | Definition IDs (DefId, LocalDefId) |
| **Generic** | 237 | Generic arguments and parameters |
| **Ty** | 139 | Type system references (TyCtxt) |
| **Trait** | 7 | Trait system references |
| **Pat** | 5 | Pattern matching |
| **Node** | 5 | Dependency graph nodes (DepNodeIndex) |
| **Res** | 4 | Resolution results |
| **Item** | 1 | AST items (MetaItemLit) |

**Not found**: Expr, Stmt, Block, Hir, Mir, Thir, ast::, hir::, mir::, thir::, Body, Impl

## Key Findings

### 1. Type System Dominance (Ty - 139 matches)
Most references are in type relation and inference code:
- `rustc_infer::infer::relate::type_relating::TypeRelating`
- `rustc_type_ir::relate::TypeRelation`
- `rustc_middle::ty::context::TyCtxt`

### 2. Definition Tracking (Def - 849 matches)
Heavy use of DefId throughout query system:
- `rustc_query_system::query::plumbing::try_execute_query`
- `rustc_span::def_id::{DefId, LocalDefId, CrateNum}`
- Query caching with DefIdCache

### 3. Generic Arguments (Generic - 237 matches)
Generic type handling in:
- `rustc_middle::ty::generic_args::GenericArg`
- `rustc_infer::infer::InferCtxt::fresh_args_for_item`
- Codegen with `GenericBuilder`

### 4. Trait System (Trait - 7 matches)
Limited but critical trait references:
- `rustc_trait_selection::solve::fulfill::FulfillmentCtxt`
- `rustc_infer::traits::engine::TraitEngine`
- `rustc_hir_typeck` integration

## Patterns NOT Found

The following were **not found** in function names:
- **Expr, Stmt, Block** - AST expression/statement nodes
- **Hir, Mir, Thir** - IR type prefixes
- **ast::, hir::, mir::, thir::** - Module paths
- **Body** - Function bodies
- **Impl** - Implementation blocks

### Why Not Found?

These types likely appear in:
1. **String values** (file paths, debug info) - not function names
2. **Type parameters** - mangled differently in symbols
3. **Local variables** - not exported in symbol names
4. **Inlined code** - optimized away

## Tool Implementation

**Location**: `query_ast_types/`

**Dependencies**:
- `parquet = "53"` - Parquet file reading
- `arrow = "53"` - Arrow data format

**Algorithm**:
1. Read parquet file with 1,921 string usage records
2. Search `function_name` field for type patterns
3. Group matches by pattern
4. Display summary statistics + examples

**Performance**: Processes 1,921 rows instantly

## Data Source

**Input**: `string_usage.parquet` (107KB)
- Generated by `extract_all_string_usage.rs`
- Contains all string references from rustc_driver.so
- Schema: string_value, string_address, instruction_address, function_name, instruction, mnemonic

**Output**: `ast_hir_mir_types_found.txt`
- Full results with examples
- 1,247 total matches across 8 patterns
