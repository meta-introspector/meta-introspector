# 🔮 The Automorphism Group of Bootstrap

## The Group Structure

```
Let C = {Mes, TinyCC, GCC, LLVM} (compilers)

An automorphism φ: C → C is a labeling that preserves structure:
  φ(c₁)(source) = binary
  where c₁ compiles source to binary

The set of all such labelings forms a group: Aut(C)
```

## Group Elements

```
Identity: id
  id(Mes) = Mes
  id(TinyCC) = TinyCC
  id(GCC) = GCC
  id(LLVM) = LLVM
  
  "Each compiler compiles itself"
  Mes(mes.c) → mes
  #️⃣ᵢ𝒹

Rotation: ρ (forward labeling)
  ρ(Mes) = TinyCC
  ρ(TinyCC) = GCC
  ρ(GCC) = LLVM
  ρ(LLVM) = Mes
  
  "Each compiler labels the next"
  Mes → TinyCC → GCC → LLVM → Mes
  #️⃣ᵨ

Inverse rotation: ρ⁻¹ (reverse labeling)
  ρ⁻¹(Mes) = LLVM
  ρ⁻¹(LLVM) = GCC
  ρ⁻¹(GCC) = TinyCC
  ρ⁻¹(TinyCC) = Mes
  
  "Each compiler extracts from previous"
  #️⃣ᵨ⁻¹

Transpositions: τᵢⱼ (swap compilers)
  τₘₜ: Mes ↔ TinyCC
  τₘ𝓰: Mes ↔ GCC
  τₘₗ: Mes ↔ LLVM
  ...
  
  "Cross-compilation swaps"
  #️⃣τ
```

## Group Operations

```
Composition: φ ∘ ψ
  (ρ ∘ ρ)(Mes) = ρ(ρ(Mes)) = ρ(TinyCC) = GCC
  
  Mes → TinyCC → GCC
  Two labeling steps
  
Powers: ρⁿ
  ρ⁰ = id
  ρ¹ = ρ (Mes → TinyCC)
  ρ² = ρ ∘ ρ (Mes → GCC)
  ρ³ = ρ ∘ ρ ∘ ρ (Mes → LLVM)
  ρ⁴ = id (Mes → Mes, orbit closes!)
  
Order of ρ: |ρ| = 4

Inverse: φ⁻¹
  ρ ∘ ρ⁻¹ = id
  Forward then reverse = identity
  
Commutativity: Generally NO
  ρ ∘ τₘₜ ≠ τₘₜ ∘ ρ
  (Order matters in compilation)
```

## Orbits

```
Orbit of Mes under ⟨ρ⟩:
  Orb(Mes) = {Mes, TinyCC, GCC, LLVM}
  
  Mes --ρ--> TinyCC --ρ--> GCC --ρ--> LLVM --ρ--> Mes
  
  This is the bootstrap cycle!
  Length: 4
  
Stabilizer of Mes:
  Stab(Mes) = {φ ∈ Aut(C) : φ(Mes) = Mes}
            = {id, τₜ𝓰, τₜₗ, τ𝓰ₗ, ...}
            
  Automorphisms that fix Mes
  (Self-compilation variants)
  
Orbit-Stabilizer Theorem:
  |Aut(C)| = |Orb(Mes)| × |Stab(Mes)|
  24 = 4 × 6 ✓
```

## Fixed Points

```
Fixed point: c such that φ(c) = c

For id: All compilers are fixed
  Fix(id) = {Mes, TinyCC, GCC, LLVM}
  
For ρ: No fixed points
  Fix(ρ) = ∅
  (Rotation moves everything)
  
For τₘₜ: GCC and LLVM fixed
  Fix(τₘₜ) = {GCC, LLVM}
  
Burnside's Lemma (counting distinct labelings):
  |Labelings| = (1/|G|) Σ_{φ∈G} |Fix(φ)|
```

## The Kernel Extraction as Homomorphism

```
Define: π: Aut(C) → Mes_variants

π(id) = Mes_original
π(ρ) = Mes_tinycc
π(ρ²) = Mes_gcc
π(ρ³) = Mes_llvm

Kernel of π:
  ker(π) = {φ ∈ Aut(C) : π(φ) = Mes_kernel}
  
  = Automorphisms that extract same minimal Mes
  
Image of π:
  im(π) = {Mes_original, Mes_tinycc, Mes_gcc, Mes_llvm}
  
First Isomorphism Theorem:
  Aut(C) / ker(π) ≅ im(π)
  
The quotient group = distinct Mes variants
```

## Conjugacy Classes

```
Two automorphisms φ, ψ are conjugate if:
  ∃ σ: ψ = σ φ σ⁻¹

Conjugacy classes in S₄:
  [id]: {id}                    (1 element)
  [ρ]: {ρ, ρ³}                  (2 elements, 4-cycles)
  [ρ²]: {ρ²}                    (1 element, 2-cycles)
  [τ]: {all transpositions}     (6 elements)
  [τ ∘ τ]: {products of 2 disjoint transpositions} (3 elements)
  
Each class = different "type" of labeling
```

## The Coherence Condition

```
A labeling φ is coherent if:
  φⁿ = id for some n
  
  (Orbit closes)

For ρ: ρ⁴ = id ✓ Coherent
  Mes → TinyCC → GCC → LLVM → Mes
  
For τₘₜ: τₘₜ² = id ✓ Coherent
  Mes ↔ TinyCC ↔ Mes
  
For general φ: Check order |φ|
  If |φ| < ∞: Coherent ✓
  If |φ| = ∞: Not coherent ✗
  
All elements of finite group have finite order
∴ All labelings in Aut(C) are coherent ✓
```

## The Witness Homomorphism

```
Define: W: Aut(C) → Hashes

W(φ) = Hash(perf.data_φ)

Properties:
  W(id) = #️⃣ᵢ𝒹
  W(ρ) = #️⃣ᵨ
  W(φ ∘ ψ) = Hash(W(φ) ∥ W(ψ))
  
This is NOT a group homomorphism (hash composition)
But it's a monoid homomorphism:
  W(id) = identity hash
  W(φ ∘ ψ) = W(φ) ⊕ W(ψ) (hash combine)
```

  (GCC ← TinyCC) ∘ (TinyCC ← Mes) = (GCC ← Mes)

Aut(C) = Automorphism group of category
```

## The Fundamental Theorem

```
Theorem: Bootstrap Coherence

The bootstrap is coherent ⟺ 
  ∃ φ ∈ Aut(C): φⁿ = id ∧ φ generates orbit covering C

Proof:
  (⟹) If coherent:
    Bootstrap closes: c₀ → c₁ → ... → cₙ = c₀
    Define φ: cᵢ ↦ cᵢ₊₁
    Then φⁿ = id (orbit closes)
    And Orb(c₀) = {c₀, c₁, ..., cₙ₋₁} = C
    
  (⟸) If φⁿ = id and orbit covers:
    Start at c₀
    Apply φ repeatedly: c₀ → φ(c₀) → φ²(c₀) → ... → φⁿ(c₀) = c₀
    This is bootstrap chain
    Orbit covers C ⟹ all compilers visited
    ∴ Bootstrap coherent
    
QED ✓

For our case:
  φ = ρ (rotation)
  |ρ| = 4
  Orb(Mes) = {Mes, TinyCC, GCC, LLVM} = C
  ∴ Bootstrap coherent ✓
```

## The Galois Connection

```
Compilers ⟷ Mes_variants
